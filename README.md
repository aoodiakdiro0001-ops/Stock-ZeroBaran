## 🎯 ما هو Stock-ZeroBaran؟

هو **نظام ذكي متكامل لمراقبة مستويات المخزون، تتبع حركة البضائع لحظة بلحظة، التنبؤ بنفاد المنتجات قبل حدوثه، وإصدار طلبات التوريد أو التنبيهات آلياً**.

يقوم بـ:
- ✅ ربط مبيعاتك ومشترياتك
- ✅ حساب معدل الاستهلاك بدقة
- ✅ تحذيرك عندما يقترب منتج معين من النفاد
- ✅ اقتراح كميات الطلب المثالية بناءً على المواسم
- ✅ إرسال تنبيهات فورية على هاتفك عبر تليجرام

> **كل ذلك دون دفع دولار واحد لأي برنامج إدارة مخزون مدفوع، وبموارد مجانية بالكامل.**

## 💡 لماذا تتمنى كل شركة وكل فرد الحصول عليه؟

### 💰 توفير مال فلكي
اشتراكات برامج إدارة المخزون وتخطيط موارد المؤسسات (ERP) تكلف ثروات طائلة سنوياً؛ هذا النظام يؤدي نفس الغرض باحترافية تامة وبتكلفة صفر.

### 🛡️ منع توقف المبيعات (Stockout Prevention)
يخبرك قبل نفاد أي سلعة بأسابيع، مما يمنع ضياع العملاء وفقدان الأرباح بسبب نقص البضاعة.

### 🔒 السيادة والسرية التجارية التامة
بيانات مخزونك، حركة التوريد، وأسماء مورديك تبقى سرية تماماً داخل خوادمك الخاصة ولا تُشارك مع أي طرف خارجي.

### تفصيل الطبقات برمجياً

#### 1️⃣ طبقة المراقبة والحسابات (Tracking & Calculation Layer)
- **التقنية:** سكريبت بايثون باستخدام مكتبة Pandas يعمل داخل خادم GitHub Actions.
- **آلية العمل:** يراجع دورياً كميات المنتجات المتبقية، يحسب معدل البيع اليومي، ويحدد بدقة متى ستصل كل سلعة إلى نقطة إعادة الطلب (Reorder Point).

#### 2️⃣ العقل التنبؤي والذكاء الاصطناعي (AI Forecasting Core)
- **التقنية:** استغلال Gemini API (أو Groq كبديل مجاني وسريع).
- **آلية العمل:** يحلل الأنماط التاريخية للمبيعات، يتنبأ بالزيادة المتوقعة في الطلب بناءً على المواسم، ويميز بين السلع سريعة الحركة والسلع الراكدة التي تلتهم مساحة التخزين.

#### 3️⃣ طبقة الأرشيف والبيانات (Persistence Layer)
- **التقنية:** قواعد بيانات Supabase PostgreSQL.
- **آلية العمل:** تحفظ جداول المنتجات، أسعار التكلفة، بيانات الموردين، وسجلات الحركات السابقة لضمان سهولة البحث والمتابعة.

#### 4️⃣ طبقة التوصيل والتنبيه (Reporting & Delivery)
- **التقنية:** Telegram Bot + Streamlit Dashboard.
- **آلية العمل:** يرسل لك تقريراً فورياً على هاتفك:

## 🚀 التثبيت والتشغيل السريع (5 دقائق)

### المتطلبات الأساسية
- Python 3.10+ (يُفضّل 3.11)
- حساب GitHub (مجاني)
- مفتاح Google Gemini API مجاني (من [aistudio.google.com](https://aistudio.google.com/app/apikey))
- (اختياري) حساب Supabase مجاني (من [supabase.com](https://supabase.com))
- (اختياري) بوت تليجرام عبر [@BotFather](https://t.me/BotFather)

### الخطوة 1: تنزيل المشروع
```bash
# استخرج الملف المضغوط
unzip Stock-ZeroBaran.zip
cd Stock-ZeroBaran
```

### الخطوة 2: تثبيت التبعيات
```bash
python -m venv venv
source venv/bin/activate        # على Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### الخطوة 3: إعداد المتغيرات
```bash
cp .env.example .env
# افتح ملف .env بمحرّر النصوص واملأ المفاتيح المجانية
```

### الخطوة 4: تعبئة بيانات تجريبية
```bash
python scripts/seed_sample_data.py
```
سيتم توليد 90 يوماً من سجل المبيعات لأنماط 8 منتجات مختلفة.

### الخطوة 5: تشغيل فحص أول
```bash
python scripts/run_inventory_check.py
```
ستظهر اللافتة، تُحسب حالة المخزون، تُبنى التنبؤات، وتُرسل التنبيهات (إن فعّلت تليجرام).

### الخطوة 6: تشغيل لوحة التحكم
```bash
streamlit run src/dashboard/app.py
```
افتح المتصفح على `http://localhost:8501`

## 🔧 التكوين المتقدم

### اختيار محرك الذكاء الاصطناعي
في ملف `.env`:
```bash
AI_ENGINE=gemini    # أو groq
```
- **Gemini** (افتراضي): دقة عالية، حصص مجانية سخية
- **Groq**: سرعة فائقة (Llama 3.3 70B)، مجاني بالكامل

النظام يتبدّل تلقائياً إلى المحرك الآخر عند فشل الأول.

### ضبط عتبات التنبيه
```bash
CONSUMPTION_WINDOW_DAYS=30       # نافذة حساب معدل الاستهلاك
FORECAST_HISTORY_DAYS=90         # تاريخ التنبؤ
FORECAST_HORIZON_DAYS=14         # أفق التنبؤ المستقبلي
CRITICAL_STOCKOUT_DAYS=5         # عتبة التنبيه الحرج (بالأيام)
```

### تعطيل بعض التنبيهات
```bash
ALERTS_ENABLED=false             # تعطيل كل التنبيهات
DASHBOARD_ENABLED=false          # تعطيل لوحة التحكم
```

## ⏰ تفعيل الجدولة المجانية عبر GitHub Actions

1. ارفع المشروع إلى مستودع GitHub (Public أو Private — كلاهما مجاني).
2. في صفحة المستودع، اذهب إلى **Settings → Secrets and variables → Actions**.
3. أضف هذه الأسرار (Secrets):
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `GEMINI_API_KEY`
   - `GROQ_API_KEY` (اختياري)
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. اذهب إلى **Actions** في المستودع، فعّل workflow اسمه "Stock-ZeroBaran Daily Inventory Check".
5. سيُشغّل تلقائياً كل يوم الساعة 08:00 UTC (≈ 11:00 بتوقيت بغداد).
6. يمكنك أيضاً تشغيله يدوياً عبر زر **Run workflow**.

> ✅ مجاني 100% ضمن حدود GitHub Actions (2,000 دقيقة/شهر للحسابات المجانية).

## 🗃️ مخطط قاعدة البيانات

النظام يحتوي على 7 جداول في Supabase PostgreSQL:

| الجدول | الوصف |
|---|---|
| `suppliers` | بيانات الموردين (اسم، اتصال، زمن التوريد) |
| `products` | كتالوج المنتجات (SKU، سعر، نقطة الطلب، مخزون الأمان) |
| `inventory_movements` | سجل كل وارد وصادر مع المرجع |
| `sales` | سجل المبيعات اليومية بمصدر البيانات |
| `stock_status` | الحالة اللحظية لكل منتج (مُحدّث آلياً) |
| `alerts_log` | أرشيف كل التنبيهات المُرسلة |
| `forecasts` | مخرجات العقل التنبؤي مع التفسير |

تفصيل كامل في `src/database/schema.sql` — جاهز للصق في SQL Editor في Supabase.
